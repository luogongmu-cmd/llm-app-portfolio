# Python 工程题 30 道（异步 / 数据结构 / 接口设计）

> 路线图第 5–6 周要求：只刷与异步、数据结构、接口设计相关的题，不刷算法竞赛题。
> 每题给 2–3 行答案，重点是「能说清取舍」，不是背定义。

## 异步（10 题）

1. **`asyncio.gather` 和 `asyncio.wait` 的区别？**
   `gather` 按传入顺序返回结果，默认一个异常会向上抛；`wait` 返回 `(done, pending)` 集合，可以设置 `return_when`，更适合「先到先处理」。

2. **同步阻塞函数直接放进 async 端点会怎样？**
   会阻塞事件循环，所有并发请求一起卡住。用 `loop.run_in_executor` 丢进线程池，或改用同步端点让 FastAPI 自己放线程池。

3. **`Semaphore` 和 `Lock` 的区别？**
   `Lock` 只允许 1 个进入；`Semaphore(n)` 允许 n 个并发，用来做并发上限和背压。项目里 `/chat` 用 `Semaphore(4)` 限制同时在跑的 LLM 调用。

4. **为什么 CPU 密集任务不适合 asyncio？**
   asyncio 是单线程协作式调度，CPU 密集会占满线程、无法让出。应该用多进程（`ProcessPoolExecutor`）或独立服务。

5. **`async for` 和普通 `for` 的区别？**
   `async for` 调用 `__aiter__` / `__anext__`，每次迭代可能 `await`；适合流式读取（SSE、数据库游标）。

6. **怎么给异步任务加超时？**
   `asyncio.wait_for(coro, timeout=10)`，超时抛 `TimeoutError`；线程池任务用 `future.result(timeout=...)`。

7. **事件循环是什么？uvicorn 里谁在跑？**
   一个不断取任务、执行、等待 I/O 的循环。uvicorn 的 worker 进程里跑一个事件循环，所有 async 端点共享它。

8. **线程池和协程池怎么选？**
   I/O 密集且库是同步的（OpenAI SDK、Chroma）→ 线程池；纯异步库 → 协程；CPU 密集 → 进程池。

9. **FastAPI 同步端点和 async 端点的执行模型？**
   同步端点由 FastAPI 放进线程池（默认 40 线程）；async 端点直接在事件循环里跑，里面不能有阻塞调用。

10. **什么是背压？怎么用 Semaphore 实现？**
    当下游处理不过来时，让上游排队而不是无限堆积。`async with sem` 把并发压到固定值，超出的请求等待。

## 数据结构（10 题）

11. **list 和 deque 做队列的区别？**
    `list.pop(0)` 是 O(n)；`deque.popleft()` 是 O(1)。项目里的限流窗口用 `deque`。

12. **dict 查找为什么平均 O(1)？**
    哈希表：key 哈希后定位桶，冲突用开放寻址/链表。最坏 O(n)，平均 O(1)。

13. **怎么用 dict 实现 LRU？**
    `OrderedDict` + `move_to_end`，超过容量时 `popitem(last=False)`。或 `functools.lru_cache`。

14. **set 去重的原理？元素要满足什么条件？**
    依赖 `__hash__` 和 `__eq__`；可变对象（list/dict）不可哈希，不能放 set。

15. **`heapq` 适合什么场景？Top-K 怎么写？**
    维护大小为 K 的小顶堆，遍历时比堆顶大就替换，最后堆里就是 Top-K，时间 O(n log K)。

16. **生成器和列表的内存差别？**
    生成器惰性求值，一次只产出一个元素；列表一次性分配全部内存。大文件/流式处理用生成器。

17. **深拷贝和浅拷贝的区别？**
    浅拷贝只复制外层容器，内层对象共享；深拷贝递归复制。`copy.copy` vs `copy.deepcopy`。

18. **可变默认参数的坑？**
    `def f(x, acc=[])` 的 `acc` 在函数定义时创建一次，多次调用共享。默认值用 `None`，函数内再初始化。

19. **字符串拼接为什么推荐 `join`？**
    `+` 每次创建新字符串，O(n²)；`"".join(parts)` 一次分配，O(n)。

20. **怎么判断两个列表是否有交集？**
    转 `set` 后 `a & b`，O(n+m)；列表大且只需判断存在性时，遍历小的建 set 更省内存。

## 接口设计（10 题）

21. **PUT 和 PATCH 的区别？**
    PUT 整体替换（幂等），PATCH 局部更新（不一定幂等）。本项目没有更新接口，但设计上要区分。

22. **幂等是什么意思？哪些方法幂等？**
    同一请求执行多次，结果一致。GET/PUT/DELETE 幂等，POST 不幂等。项目里用 `request_id` 做去重。

23. **429 和 503 的区别？**
    429 是客户端请求太多（限流），503 是服务端暂时不可用（过载/依赖故障）。限流返回 429，异常降级返回 503。

24. **分页接口怎么设计？cursor 和 offset 怎么选？**
    offset 简单但深分页慢、数据变动会重复/漏；cursor 基于排序键，稳定且快。大数据量用 cursor。

25. **为什么 API 要返回 `request_id`？**
    排查问题时能把日志、调用链、用户反馈串起来；也用于幂等重试。

26. **超时、重试、幂等三者怎么配合？**
    超时后重试必须幂等，否则会重复下单/重复计费。重试要指数退避 + 上限，且只对可重试错误（5xx/超时）重试。

27. **接口版本怎么管理？**
    URL 前缀 `/v1`、Header 或 Content-Type。破坏性变更升版本，旧版本保留过渡期。

28. **错误响应应该包含什么？**
    HTTP 状态码 + 稳定错误码 + 可读 message + `request_id`；不要返回堆栈和内部路径。

29. **为什么不要把内部异常直接返回给用户？**
    泄露实现细节和安全信息；用户也看不懂。返回「服务暂时不可用」+ 日志里记录完整堆栈。

30. **怎么设计限流器？令牌桶 vs 滑动窗口？**
    令牌桶允许突发、按速率补充；滑动窗口统计最近 N 秒请求数，边界更精确。项目里用 deque 做 60 秒滑动窗口，每角色 20 次/分钟。
